CADERNO DE CAMPO — AGROPECUÁRIA PAINEIRA — VERSÃO CELULAR

Principais recursos:
- Interface adaptada para celular.
- Propriedade padrão: AGROPECUÁRIA PAINEIRA.
- Aplicador padrão: MARCIO GRIGOLETTO ESPINDOLA.
- CPF padrão: 976.068.470-53.
- Campos de data com calendário nativo do celular.
- Impressão mostra as datas em DIA-MÊS-ANO.
- Botão para obter latitude e longitude pelo GPS do celular.
- Histórico, edição e exclusão.
- Impressão da ficha.
- Backup e restauração em arquivo JSON.
- PWA: pode ser adicionada à tela inicial e funcionar offline após instalada.

IMPORTANTE SOBRE O GPS:
Navegadores de celular exigem uma origem segura (HTTPS) e permissão de localização para fornecer GPS.
Abrir index.html diretamente como arquivo não garante que o GPS funcione.

COMO COLOCAR NO CELULAR:
1. Publique esta pasta em uma hospedagem HTTPS (pode ser hospedagem estática gratuita).
2. Abra o endereço no Chrome/Edge/Safari do celular.
3. Permita acesso à localização quando solicitado.
4. Escolha "Adicionar à tela inicial" / "Instalar aplicativo".
5. Depois da instalação, os dados ficam guardados no próprio aparelho e o app funciona offline.

BACKUP:
Use a aba Backup para exportar periodicamente os registros. O backup é importante porque os dados ficam no aparelho.
